# Fraud Detection & Payment Risk Analytics

## Project Overview

This project analyzes financial transaction data to identify fraudulent transaction patterns, suspicious activity, anomalies, and high-risk segments.

## Objective

The objective is to use SQL, Python, and Power BI to analyze transaction behavior, identify fraud indicators, and create a fraud monitoring workflow.

## Tools Used

- SQL
- Python
- Pandas
- NumPy
- Scikit-learn
- Power BI
- Excel

## Analysis

The analysis focuses on transaction frequency, transaction amounts, customer activity, geographic patterns, merchant behavior, anomalies, and fraud indicators.

## Fraud Detection

Python and statistical techniques are used to identify abnormal transaction behavior, perform feature engineering, analyze class imbalance, and segment transactions based on risk.

## SQL Analysis

SQL is used to investigate transaction patterns, transaction frequency, transaction values, customer behavior, merchant activity, and suspicious transactions.

## Power BI Dashboard

The dashboard monitors:

- Fraud Rate
- Transaction Volume
- Fraud Transactions
- Suspicious Transactions
- Risk Segments
- Geographic Trends
- Transaction Anomalies
- Investigation KPIs

## Business Recommendations

The analysis helps prioritize suspicious transactions, identify emerging fraud patterns, improve monitoring, and support data-driven fraud prevention decisions.

## Conclusion

The project demonstrates an end-to-end fraud analytics workflow using SQL, Python, and Power BI.
